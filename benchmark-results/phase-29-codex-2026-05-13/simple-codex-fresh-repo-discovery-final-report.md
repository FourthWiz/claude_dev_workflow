# Simple Codex Fresh Repo Discovery Report

## Project Purpose

Quoin is a workflow-memory toolkit for coding agents. Its primary value is the
portable workflow contract: `.workflow_artifacts/`, planning and review
artifacts, session handoff, lessons learned, and cost-ledger semantics that can
be used across runtimes. Claude Code is the currently supported runtime adapter;
Codex support is scaffolded through repo-local `AGENTS.md` guidance and adapter
documentation.

## Main Code And Documentation Areas

- `AGENTS.md`: repo-local Codex guidance and architectural constraints.
- `README.md`, `CHANGELOG.md`, `runtime-portability-migration-plan.md`: top-level
  user and migration context.
- `quoin/core/workflow/`: runtime-neutral workflow rules, artifact layout,
  session-state, cost-ledger, and skill metadata.
- `quoin/core/skills/`: portable intent documents for the 21 workflow skills.
- `quoin/scripts/` and `quoin/core/scripts/`: validation, path resolution, cost,
  preamble, and adapter-drift scripts.
- `quoin/adapters/claude/`: Claude adapter docs and skill files.
- `quoin/adapters/codex/`: thin Codex adapter scaffold, generator, readiness
  check, smoke test, unsupported Claude behavior notes, and generated skill docs.
- `quoin/benchmarks/`: Phase 29 design-only benchmark framework.
- `quoin/docs/`: runtime portability and parity documentation.
- `quoin/dev/`: developer docs, measurement utilities, tests, and fixtures.

## Risks And Unknowns

- The worktree is not clean: Phase 29 benchmark files and runtime portability
  docs are already modified or untracked, so benchmark evidence must avoid
  treating those changes as generated by this trial.
- The Phase 29 framework is explicitly design-only. It validates scenario and
  template structure but does not automate isolated runtime runs.
- Codex cost capture is not implemented in the repo, so cost must be recorded as
  `not available`.
- The current fixture is this active repository, not a reset clean checkout.
  That limits strict cross-mode comparability.
- `src/quoin/` contains only `__pycache__` files in this checkout, and no Python
  package manifest was found by the discovery commands. Packaging state needs
  separate confirmation before release work.
