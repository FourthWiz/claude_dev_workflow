Keyboard shortcuts

  • h / ? — toggle this help overlay
  • Esc — clear filters, close detail panel & help

Filters

Use the left sidebar to filter by layer (lane) or by artifact tier. The search box highlights matching nodes.

Layout

Toggle between cose (force-directed) and dagre (hierarchical) layouts using the button in the sidebar.

Navigation

Click a node to open the detail panel. Hover a node to highlight its 1-hop neighborhood. Scroll to zoom; drag to pan.
